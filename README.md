# Retail Intelligence

Proyecto de analítica de datos orientado a la optimización del desempeño operacional de una empresa retail.

## Objetivo

Analizar ventas, demanda e inventario para identificar problemas operacionales, evaluar KPIs y estimar oportunidades de mejora mediante datos.

## Tecnologías

- Python
- Pandas
- NumPy
- Jupyter Notebook
- Excel
- Power BI
- Git
- GitHub
